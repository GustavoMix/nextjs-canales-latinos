TV LATINO WEB - PASOS RAPIDOS
=============================

ANTES: publica el repo channelwatch-cron bajo la MISMA cuenta de GitHub.

1) Crea en GitHub un repositorio PUBLICO llamado exactamente:
   tv-latino-web

2) Sube TODO el contenido de esta carpeta a la rama main.

3) GitHub -> Settings -> Pages -> Source -> GitHub Actions.

4) Al hacer push a main, GitHub construye y publica la web automaticamente.

URL esperada:
https://TU-USUARIO.github.io/tv-latino-web/

La web encuentra sola los datos en:
https://TU-USUARIO.github.io/channelwatch-cron/data

No necesitas SINCRONIZAR_JSON.bat en produccion.
Ese BAT queda solamente para pruebas locales.
